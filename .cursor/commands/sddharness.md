# /sddharness

Siga `template/.claude/commands/sddharness.md` (este kit) ou o comando instalado no repo alvo.

```

sddharness usage
/sddharness init | filldocs | jira | task | write-spec | approve | usage | config

`start` abre o leader no executor do config global e conduz tarefa nova ou pendente
(sem precisar de `/sddharness init`).
```
